# fredgar-ai documentation

> Every document in this repository, one line each — start with the root README, and see AGENTS.md for how to work here.

**Backlog of record:** GitHub Issues with the fleet labels ([`.github/sdlc.yml`](../.github/sdlc.yml) `backlog.mode: issues`).

Start with the [root README](../README.md) for setup, Docker and tests, and [AGENTS.md](../AGENTS.md) for commands and conventions. The route and command tables under [`reference/`](reference/) are generated by `python3 tools/gen_reference.py --write`. Outside `docs/`, folder guides live beside their code: [`data/README.md`](../data/README.md) (reference JSON and the commands that regenerate it), [`docker/README.md`](../docker/README.md) (container scripts), [`frontend/README.md`](../frontend/README.md) (the UI) and [`tools/README.md`](../tools/README.md) (repo scripts).
